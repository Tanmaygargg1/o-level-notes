| Part       | Function                                                                                                                                                                                                                                                                                                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Ovary   | - 2 ovoid ovaries -> produce ova (eggs)<br>- each ovary -> also produces hormones such as *oestrogen* and *progesterone*<br>- female sex hormones -> responsible for development and maintenance of secondary sexual characteristics in females<br>- when eggs become mature -> they are released from ovaries                                                                  |
| 2. Oviduct | - each ovary -> releases mature eggs -> into an oviduct<br>- oviduct -> narrow, muscular tube -> leading from ovary to uterus. Has *funnel like opening* -> lying close to ovary. makes it easier for egg to enter oviduct<br>- egg usually fertilised in oviduct<br>- inner surface -> of oviduct -> lined with *cilia*. movement of cilia helps to move egg along oviduct.    |
| 3. Uterus  | - uterus / womb -> where *fetus* / *foetus* ot unborn baby -> develops during pregnancy. <br>- uterus -> shaped like upside down pear. has *elastic muscular walls*. the *smooth muscle tissue* in the walls of the uterus -> contract -> push foetus out during birth<br>- *soft, smooth inner lining* of uterus -> called *uterine lining*. It is where embryo is *implanted* |
| 4. Cervix  | - *ring of muscles* at lower portion of uterus -> where it joins vagina<br>- opening of cervix -> allows menstrual blood -> to flow out into vagina -> during menstruation                                                                                                                                                                                                      |
| 5. Vagina  | - vagina / *birth canal* -> leads from cervix to outside<br>- semen deposited in vagina during sexual intercourse                                                                                                                                                                                                                                                               |
