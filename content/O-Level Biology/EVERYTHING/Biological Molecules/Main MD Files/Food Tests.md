## Benedict's test for reducing sugars

| Benedicts Test for Reducing Sugars                                                                                                                                                                                                                                                                                                                                     |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Procedure for liquid:<br>1. add an equal volume of Benedicts solution to the sample in a test tube<br>2. Shake thoroughly<br>3. Place the test tube in a beaker of boiling water for 2-3 minutes                                                                                                                                                                       |
| Procedure for solid:<br>1. add finely chopped sample into a test tube containing 2cm3 of denoised water<br>2. Shake thoroughly<br>3. Allow solids to settle <br>4. decant the liquid into another test tube <br>5. Add equal volume of benedicts solution into the test tube<br>6. Shake thoroughly<br>7. Place test tube in a beaker of boiling water for 2-3 minutes |
| Positive result:<br>benedicts solution turns from blue to green/orange/yellow/red <mark style="background: #FFB86CA6;">precipitate</mark> <mark style="background: #FF5582A6;">upon heating</mark>                                                                                                                                                                     |
| Negative result:<br>Benedicts solution remains blue upon heating                                                                                                                                                                                                                                                                                                       |

|                                                        |                                    |
| ------------------------------------------------------ | ---------------------------------- |
| Solution remained blue                                 | No reducing sugars                 |
| Solution turned from blue to green precipitate         | traces of reducing sugars          |
| solution turned from blue to yellow/orange precipitate | moderate amount of reducing sugars |
| solution turns from blue to red precipitate            | large amounts of reducing sugars   |

| Reducing Sugars                                                                          | Non-Reducing Sugars                                                   |
| ---------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| - glucose<br>- fructose<br>- Maltose<br>- Lactose<br>- Glyceraldehyde<br>- Arabinose<br> | - Stachyose<br>- Sucrose<br>- Tehalose<br>- Verbascose<br>- Raffinose |

## Test for Starch
Add a few drops of iodine solution to sample on a white tile
*positive result*
iodine solution turns from yellow/brown/yellowish-brown to blue back
*negative result*
iodine solution remains yellow/brown/yellowish-brown

## Alcohol Emulsion Test for Fats

| Alcohol Emulsion Test for Fats                                                                                                                                                                                              |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Procedure for Liquid<br>1. add 2Cm3 of ethanol to a drop of the sample<br>2. Shake thoroughly<br>3. Add the solution to 2cm3 of water in a test tube<br>                                                                    |
| Procedure for Solid<br>1. add finely chopped sample into a test tube containing 2cm3 of ethanol<br>2. shake thoroughly<br>3. Allow solid to settle<br>4. Decant the liquid into another test tube containing 2cm3 of water. |
| Positive Result:<br>A cloudy white emulsion is formed (remember to state the change)<br>                                                                                                                                    |
| Negative Result:<br>Solution remains clear                                                                                                                                                                                  |

## Biurets Test for Proteins

| Biurets Test for Proteins                                                                                                                                                                                                                                                                                                                                  |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Procedure for Liquid:<br>1. add an equal volume of sodium hydroxide to the sample in a test tube<br>2. add a drop of Copper(II)sulfate solution - shake after each drop<br>OR<br>1. add an equal volume of biurets solution to sample in a test tube<br>2. shake well and allow mixture to stand for 5 minutes                                             |
| Procedure for Solid<br>1. Add finely chopped sample into a test tube containing 2cm3 of deionised water<br>2. shake thoroughly<br>3. Allow solids to settle<br>4. Decant the liquid into another test tube<br>5. Add an equal volume of sodium hydroxide to sample in the test tube<br>6. add a drop of Copper(II)sulfate solution - shake after each drop |
| Positive Result:<br>Solution turns from blue to violet<br>                                                                                                                                                                                                                                                                                                 |
| Negative result:<br>Solution remains blue                                                                                                                                                                                                                                                                                                                  |
