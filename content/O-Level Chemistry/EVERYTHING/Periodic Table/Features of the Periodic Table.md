1. elements in periodic table -> arranged in periodic table in order of proton number (atomic number)

2. Vertical columns in periodic table -> called **Groups** and horizontal rows are called **Periods**

3. Elements in periodic table -> classified as metals, non-metals, metalloids. 
- Metals and non-metals are separated by -> *Hays McDaniel Line* 

4. **Atom of elements in same group have same number of valence electrons**
- For elements 13-18 (except helium) -> number of valence electrons is the group number minus 10. (E.g. chlorine has 17-10 = 7 valence electrons)

5. **Atoms of elements in same period have the same number of electron shells**

___
>[!important]
>Number of electron shells an element has is the same as its period number

>[!note]
>Elements with the same number of valence electrons have similar chemical properties. -> as valence electrons are involved in chemical reactions. 
>we can thus deduce -> that elements in the same group -> have similar chemical properties
