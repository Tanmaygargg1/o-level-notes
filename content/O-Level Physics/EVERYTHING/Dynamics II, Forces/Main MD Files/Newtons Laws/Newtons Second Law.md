if resultant force acting on an object is not 0, we say forces on the object are unbalanced. 
___
![[Pasted image 20240907230740.png|500]]
Forces acting on book are balanced => and it moves at constant velocity. 
if applied force F => is now increased => forces that act on the book => no longer balanced => and book accelerates.

If applied force F is removed => while book is still in motion -> friction is the resultant force.
Resultant force => causes book to decelerate and eventually stop . 
___
>[!law]
>Newtons second law states that when a resultant force acts on an object of a constant mass, the object will accelerate in the direction of the resultant force.
#PhysicsDefinitions 

___
Product of mass and acceleration of object gives resultant force.
$$ F = ma$$
F = resultant force (N)
m = mass of object (Kg)
a = acceleration of object ($m/s^2$)
#physicsFormulae 
___
- resultant force F of an object => produces an acceleration, a
- Doubling the resultant force F of an object doubles its acceleration
- with the same resultant Force F, doubling mass m halves the acceleration, a
___
Force => is directly proportional to acceleration
Force=> is inversely proportional to mass. 
* inverse proportion graph is a downward curve
