>[!definition]
>Speed is the distance traveled per unit time
#PhysicsDefinitions 

<span style="color:rgb(0, 176, 240)">speed: scalar quantity: cannot be negative</span>

Average speed => assumes that speed is the same throughout entire distance.
- reality: speed not same throughout distance traveled
- Speed at 1 instant => may be diff from speed at another distant
- Speed of a particular object at a particular instant is known as <mark style="background: #BBFABBA6;">instantaneous speed. </mark>

*Formulas:*
$$Speed = \frac{distance}{time}$$
$$Average speed = \frac{total\ distance\ covered}{total\ time}$$
#physicsFormulae 

Uniform speed: 
- if change in distance travelled by an object for every unit of time is the same => object undergoes constant/uniform speed
