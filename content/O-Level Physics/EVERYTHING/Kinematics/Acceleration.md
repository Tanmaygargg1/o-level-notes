- object accelerates when velocity changes
___
>[!definition]
>acceleration is the rate of change of velocity per unit time.
#PhysicsDefinitions 

___
Object undergoes acceleration when: 
- speed or direction changes
- both its speed and direction change
![[Pasted image 20240906165231.png|700]]

SI unit: $m/s^2$
___
*Formula*
$$Acceleration = \frac{change\ of\ velocity}{time\ taken}$$
$$uniform acceleration, a = \frac{\Delta v}{\Delta t} = \frac{v - u}{t_v - t_u}$$
change v = change in velocity (m/s)
change t = time interval between $t_v$ and $t_u$ (s)
V = final velocity
U = initial velocity
$t_v$ = time at which object is at final velocity (s)
$t_u$ = time at which object is at initial velocity

>[!important]
>reformulation: $v = u + at$ 

___
Acceleration => VECTOR => can be negative
___
**Uniform acceleration**
- change (increase/decrease) in velocity of object for every unit of time = same
- Object undergoes constant/uniform acceleration

>[!definition]
>Uniform acceleration is the constant rate of change of velocity
#PhysicsDefinitions 

___
Non uniform acceleration: 
- object undergoes non uniform acceleration if change in velocity for every unit of time is NOT the same
___
key words:
- increases with increasing rate
- increases with decreasing rate
- same phrasing for decrease.

>if the qn says deceleration you can give raw value. if it says acceleration and the object is decreasing, then must put down a (-)
