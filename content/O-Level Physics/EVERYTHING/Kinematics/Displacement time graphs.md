___
Displacement time graph: gradient of a displacement time graph gives us velocity of the object
___
Describing displacement time graphs:
- Velocity
- direction
- reference to starting point



Car moves in opposite direction from which is started (negative displacement) when displacement is below the X axis
when graph is decreasing, but still above x axis => car moves back to its original point => from which it started
When this happens: state: the care is still in positive direction form starting point, but it is moving back towards starting point
